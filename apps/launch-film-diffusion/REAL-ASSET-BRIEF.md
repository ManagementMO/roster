# Real asset pass

This pass addresses the “AI-generated graphics” problem while preserving the short, fast cut.

## Direction

Use a believable local terminal as the visual anchor, then let recognizable tool marks carry the story. The film is still deterministic and code-native, but the visual nouns now come from real source material: GitHub, Playwright, Linear, PostgreSQL, and Claude. Filesystem is the only exception because it has no canonical vendor mark; it uses a restrained folder glyph.

## Terminal truth

The shell transcript is authored from the repository’s documented launch surface: `npx roster init` and `roster sync --five`. It is not a recording of a private machine and does not claim a cloud service, account, or silent substitution. The terminal is rendered as a real-time playhead-driven shell with cursor, typed output, perspective, and a camera push into the command surface.

## Motion guardrails

The terminal gets the longest readable hold. Candidate marks enter one at a time. The Starting Five has explicit collision-safe slots, staggered shell/mark/text reveals, and a short hold before the call-path transition. The current motion pass uses one repeatable rhythm: accelerate into the beat, pop the new object or character, then settle it with a restrained overshoot. Typed terminal characters, route packets, hero cards, Roster bars, and the final mark all use this same arrive-pop-settle grammar. Every mark is cached once as a local path to keep Studio responsive.

## Asset policy

No stock photo, generated image, or remote runtime URL is used. Source URLs and licensing notes are in `assets/brands/ASSET-SOURCES.md`. If a future pass adds an actual screen recording, capture a clean disposable demo environment and keep its transcript and license beside the media.

## Diffusion Studio reference

The [Diffusion Studio launch-video repository](https://github.com/diffusionstudio/launch-video) is also written as a code-native JSX composition with local footage/artwork, a command-first cold open, strong kinetic typography, explicit scene handoffs, and authored timing. This pass borrows those craft principles—especially the readable command surface and deliberate handoff rhythm—without copying its footage, brand assets, or human performance.
