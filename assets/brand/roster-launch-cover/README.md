# Roster launch covers

Created September 8, 2026 for the approved 15-second Roster launch film.

The landscape cover is the primary launch artwork. The feed edition recomposes the same design for a short portrait frame.

## Final artwork

- `roster-launch-cover-landscape.png` — 1672 × 941 pixels, landscape.
- `roster-launch-cover-feed.png` — 1122 × 1402 pixels, portrait / feed.
- `roster-launch-covers.zip` — both PNGs, the prompts, this guide and the delivery manifest.

Headline: **200 tools. Your starting five.**

Secondary line: **Your local MCP tool router.**

The covers use a matte navy background, pearl headline, cobalt emphasis, and five distinct tool brands: GitHub, Figma, Playwright, Linear and PostgreSQL. Each tool appears once per cover, with recognizable original-color artwork.

## Generation and identity

Both final PNGs were made with the built-in image-generation tool, using the approved launch film and the canonical slim R with longer legs as references. The full final prompts are in `prompt-landscape.txt` and `prompt-feed.txt`. The PNGs are copied directly from the generated originals without raster post-processing.

The first portrait draft was rejected because its canvas was too narrow. The delivered feed image is the subsequent composition made using the existing feed poster as the target canvas reference.

Reference artwork lives in:

- `assets/brand/roster-r-01/roster-mark-pearl-1024.png`
- `assets/brand/roster-r-01/roster-lockup-pearl.png`
- `videos/roster-premiere-tight/renders/roster-tight-contact-sheet.png`
- `videos/roster-premiere-feed/renders/roster-feed-poster.png`

These are raster campaign illustrations. The canonical reusable identity remains the exact SVG kit in `assets/brand/roster-r-01/`; the generated covers do not replace those vectors.

## Review

Visually reviewed both final covers for headline spelling, clear hierarchy, unclipped content, palette consistency, five distinct brands and the slim R silhouette. Actual export dimensions, file sizes and SHA-256 hashes are recorded in `delivery.json`.

No film timeline, website source, brand source vectors or public destinations were changed by the cover task.
