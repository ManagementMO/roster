## Intent

Create a fast, bubbly, poppy, premium launch trailer for Roster. The film begins with
an impossible universe of tools, then uses elastic editorial motion to turn overload
into one clean endpoint and five deliberate starters. It must work muted, read clearly
after social compression, and feel like one continuous camera move rather than a deck.

## Customizations

- Use large white-and-ink surfaces, saturated product blue, soft glass, rounded geometry,
  and crisp shadows; avoid neon cyan/purple HUD styling.
- Make motion playful but weighted: squash, recoil, overshoot, curved travel, staged
  secondary reveals, and velocity-matched seams. Never use idle wobble.
- Build an original, non-generic rhythm-and-sound-design bed with tactile impacts,
  terminal ticks, scan movement, routing clicks, one failure interruption, and a clean
  final resolve. No narration.
- Center the factual story on the Rotation, the Coach, the starting five, the
  suggestion-only Sixth Man, and a PRE-SEASON League glimpse.

## Notes

- The repository is pre-release and the package is not published. If the planned
  `npx roster init` command appears, label it as the launch command or pair it with
  "coming soon" rather than implying it works from npm today.
- Sixth Man is suggestion-only: the agent must visibly accept before any replacement
  path completes.
- Do not imply cloud routing. Roster operates locally; telemetry is off by default.
- Keep all work isolated to this HyperFrames project and do not modify the existing
  Remotion or Diffusion Studio launch-film applications.
