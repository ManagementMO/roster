The orbit now intentionally excludes runtime/model marks such as Claude and OpenAI, plus npm and Docker: every orbit mark is an agent-facing work, data, design, observability, payment, or infrastructure integration with a documented MCP or comparable agent connector. Filesystem is represented by a small native folder glyph because it has no single canonical vendor logo. No stock photography, generative image, or remote runtime asset is used in the real-asset pass.
