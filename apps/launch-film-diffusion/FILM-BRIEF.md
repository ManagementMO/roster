# Film brief

The active film is a 12.4-second social launch punch. It communicates one idea without narration: an agent can have 200 available tools, while Roster ranks the capabilities that best fit the current task and routes the request locally. The edit remains intentionally compact: the separate Starting Five lineup scene was removed so the remaining beats finish, settle briefly, and hand off without dead time.

## Audience and objective

Developers using MCP-capable agents should understand `200 → 5` during the first 1.35 seconds, recognize a believable local terminal setup, see an agent intent become a ranked capability decision, and retain the product name and `npx roster init` command.

## Visual direction

The film uses paper white, cool graphite, smoke-silver glass, soft sage, and restrained copper brand moments, while native product marks retain their natural colours. Five large glass tool objects carry real GitHub, Playwright, Linear, PostgreSQL, and Claude marks; Filesystem uses a warm native folder glyph, and the supplied Roster mark is the vivid multicolour identity anchor. Avenir Next leads the display typography, with a local system fallback stack for portable renders. Scale comes from bold typography, a believable terminal shell, the single-rail fit shortlist, the physical Roster aperture, and decisive white/dark contrast—not particles, tiny cards, HUD labels, purple haze, turquoise fog, or decorative sprites.

## Motion and audio

Motion follows a leftward current. Each seam cuts while moving and carries a concrete object: the Roster route mark, the fit rail, the request token, or the final orbit. The motion grammar is `accelerate → pop → settle → handoff`: typed characters scale briefly as they appear, candidates rise only when the fit beam reaches them, the aperture carousel locks decisively, and the result stays visible just long enough to read before the identity transition. Mixkit's propulsive **Minimal Techno 01** supplies the musical drive, while deterministic launch cues add selection clicks, soft smoke-route pulses, aperture impacts, transitions, and the final resolve.

## Factual boundary

The teaser shows the truthful launch command `npx roster init`, local routing, task-based ranking, and a five-capability shortlist. The ranked-route beat uses an illustrative `verify checkout flow` intent and illustrative returned evidence to make the routing behavior legible; it does not claim a live production run. The hook frames the problem as 200 tools polluting an agent's context; the final lockup resolves that to “ONLY THE ONES THAT MATTER START.” The terminal uses a designed deterministic transcript rather than a personal machine capture; the command and local-first claims are sourced from the repository README. The compressed format intentionally omits Sixth Man, Coach, League, and the longer Starting Five lineup treatment rather than presenting them without enough time for accurate context.
